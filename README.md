# 🎵 MusicPulse - Music Listening Analysis System

A simple R Shiny application to track and analyze your music listening data WITHOUT using ML/DL - purely using basic R concepts.

### 🔥 Features
- **1. Music Data:** View raw dataset of 12 songs (Song_ID, Artist, Genre, Rating, Listening_Count)
- **2. Extract:** Extract any column data using c() & indexing
- **3. Sequence:** Generate playlist ID sequence using seq()
- **4. Combine:** Combine months using c() & unique genres using unique()
- **5. Monthly Listening:** Bar chart visualization for monthly count (Jan:25, Jul:28, Dec:18)
- **6. Average Rating:** Calculate mean() rating of favorite songs
- **7. Summary:** Total Songs: 12, Total Listening: 376, Avg Rating: 4.08

### 🛠️ Tech Stack
- R Programming
- R Shiny (UI on 127.0.0.1:3064)
- Concepts Used: c(), seq(), unique(), mean(), length(), barplot

### 🚀 How to Run
1. Clone repo
2. Install R & RStudio
3. `install.packages(c("shiny","dplyr"))`
4. Run `app.R`
